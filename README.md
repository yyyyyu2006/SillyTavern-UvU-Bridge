# UvU Story Bridge for SillyTavern

This project is a local, opt-in bridge between the UvU phone UI and SillyTavern. It keeps online UvU turns and offline SillyTavern scenes as separate, source-tagged records. It does not rewrite either app's base prompt.

## Current status

The repository includes the SillyTavern UI extension, local server plugin, protocol tests, and the reusable browser client at `client/uvu-bridge-client.js`. The matching UvU-side connection panel is maintained in the separate UvU app repository; users need a UvU deployment that includes that integration for end-to-end use.

The repository contains both parts required by the bridge:

- A SillyTavern UI extension for pairing, mode control, memory context, and scene export.
- A SillyTavern server plugin that exposes the authenticated local API used by UvU.

SillyTavern server plugins run with server-side privileges. Review the source before installing and only enable server plugins if you trust it.

## Intended behavior

- Online mode leaves normal UvU chat behavior unchanged.
- When connected, UvU checks the mapped character's mode before generating a reply. Offline mode blocks the UvU reply; the phone mode allows it.
- Successful UvU turns are sent to the local bridge as continuity records. The server does not call an LLM or rewrite UvU prompts.
- Offline scene mode captures the selected SillyTavern chat only after the user starts a scene.
- UvU messages are held as source-tagged memory events; they are not silently inserted into the SillyTavern chat transcript.
- SillyTavern scene exports are delivered to the mapped UvU character's existing memory-journal list as a draft. They are not injected by default; enabling the UvU setting uses its existing favorited-memory path.
- Memory injection is opt-in and uses SillyTavern's extension-prompt facility, not edits to the character card or base prompt.
- Switching modes never deletes either app's source conversation.

## Installation overview

Install the repository twice because the UI extension and server plugin run in different parts of SillyTavern:

1. Add the repository URL in SillyTavern's third-party extension installer to install the UI panel.
2. Clone the same repository into `<SillyTavern>/plugins/uvu-story-bridge` for the server plugin.
3. From that plugin directory, run `node setup-server-plugin.js`. The script asks for the exact HTTPS UvU origin, displays the changes, and applies them only after the user types `APPLY`. It backs up `config.yaml` and any existing `server/config.json`, enables server plugins, and adds the origin to the bridge allowlist. The client API listens on a separate loopback-only port (default `8765`), so the setup does not disable CSRF or change SillyTavern's global CORS settings. Restart SillyTavern afterward.
4. In UvU's **酒馆互通** page, enter the local bridge address and paste the short-lived pairing code generated by the SillyTavern UI panel, then click **连接 / 配对**.
5. Pairing publishes the UvU character ID/name directory to the local bridge. In SillyTavern, choose the matching UvU character from the dropdown for the currently selected Tavern character. The panel displays both sides of the mapping; starting a scene is blocked if the UvU character is not verified in the directory.
6. In UvU, hand off the selected range from the intended character/archive. In Tavern, browse and review received entries, then explicitly press **设为下场记忆来源** before starting a scene. Browsing another archive during an active scene never changes its pinned memory source or export destination. Start a scene to lock the character, chat and source archive; **拿出手机** opens the UvU message channel. End the scene in SillyTavern to export it to the mapped UvU character's review draft. Review and save the selected text in UvU before it becomes usable diary memory.

Version 0.3.0 adds a persistent Tavern master switch, exact scene/chat/archive isolation and a version checker. Disabling clears only this extension's prompt, cancels its pending work and returns UvU modes to online. Re-enabling or refreshing the extension does not silently resume a scene: return to its original chat and press **继续本场**. Other Tavern extensions and original source conversations are unchanged.

**检查版本 / 更新** reads the running server version and the public repository manifest; it does not upload chats or install code. Update the UI through Tavern's extension manager and refresh the page. Update the separate server-plugin checkout with `git pull`, then stop the running Tavern process with Ctrl+C and restart it with the user's normal startup command. Refreshing a browser tab cannot update an already-running Node server. The in-app tutorials explain every button, both review directions, errors and recovery.

For a GitHub Pages project, the bridge address entered in UvU is `http://127.0.0.1:8765/api/plugins/uvu-story-bridge` by default. This is the plugin's separate loopback client API, not SillyTavern's main port. If you change `clientPort` in `server/config.json`, use that port in UvU too. Start pairing from a visible UvU page by clicking the connect action. Browser local-network permission and mixed-content behavior vary by browser/version and must be tested on the target device. Background pages may pause, so the client resumes from sequence cursors when brought back to the foreground.

The UI extension and server plugin must both be installed. The extension manager cannot install or enable a server plugin on a user's behalf. Server plugins are not sandboxed and can access server-side resources; review the code before enabling one.

The setup script edits local configuration only after the user types `APPLY`; it creates timestamped backups first. The extension manager cannot install or enable a server plugin on a user's behalf. The visible panel is under SillyTavern's **Extensions** settings as **UvU Story Bridge · 线下剧情互通**. If it does not appear, verify that the UI extension is installed and enabled separately from the server plugin, then refresh the page. ## Data and security

- The API is intended for a SillyTavern instance on the same device as UvU.
- Cross-origin requests require an explicit origin allowlist and a paired bearer token; the separate client API binds only to `127.0.0.1`.
- Pair codes expire and can only be redeemed once. Tokens can be revoked from either side.
- The plugin rejects non-loopback clients by default.
- Local event and memory records are stored under `server/data/`, which is excluded from Git.
- Do not expose the SillyTavern server port to the public internet. CORS is not authentication.
