# 审核与诊断优化（2026-11-06）

UvU审核清单每页10场，可按待审核或关键词筛选。展开一场后每次加载20层，楼层展开才创建编辑器。“全选本场全部楼层”包含尚未加载的楼层；保存与总结也使用全部选择。

本机原文编辑草稿按ST/TT通道、角色、存档、场景和原文版本区分。页面刷新可恢复；原文更新不会自动套旧选择，可展开差异并明确迁移同ID楼层。此草稿保存在当前浏览器网站数据中，清网站数据会丢失；完成审核后的日记仍由UvU正式存储保存。

ST正文规则按角色保存。导出预览显示原楼层、命中标签、过滤块、未知标签和提取结果；未知标签须确认，破损正文标签仍阻止导出。任意预设都能自动正确识别不是本功能承诺；更换预设后应核对规则。

摘要先展示字符/分组/预计调用；实际请求受本轮调用次数预算限制。失败或预算到达时保留原文和成功分组缓存。按来源版本持久保存最多200组／1MiB，原文或模型要求变化时不复用旧组；超过限额的分组可能需再次调用。完整摘要仍须预览并确认，才成为记忆。

UvU连接分层面板区分设备凭据保存、服务可达、版本/协议、角色存档、交接回执、审核保存和注入允许。服务容量数字是全局保留事件容量；本机待发容量是当前通道500条。服务接收不等于另一端已审核。

“导出脱敏诊断”只导出状态和计数，排除地址、凭据、角色标识与正文。“导出本通道恢复副本”包含剧情正文和恢复元数据，须自行保管；它不清除原队列，当前没有自动导回恢复器。恢复收取不会仅因服务缺片删除已有未完成场景。

TT文件模式无服务器、无配对、无部署命令，须人工交换文件；不控制另一端线上/线下状态。HTTPS模式须自行部署独立中继，后台仍可被系统暂停；保持精确来源白名单，不能开放任意来源解决报错。

已完成的重复场景副本和完成态摘要缓存可先预览清理范围、导出恢复副本，再明确确认清理。正式日记、未完成剧情和去重回执保留；不按年龄自动删除。恢复副本当前没有自动导回入口。
